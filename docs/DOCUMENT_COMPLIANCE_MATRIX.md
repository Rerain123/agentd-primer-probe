## 判定口径

- `已实现`：代码、科学工具调用和自动测试均可证明满足文档要求。
- `部分实现`：已有编排或计算代码，但仍有判定细节、数据来源或测试证据缺失。
- `环境阻塞`：代码入口存在，但当前运行环境缺少文档要求的工具或数据库。
- `未实现`：文档步骤尚无对应生产实现。
- 开发降级算法、精确字符串匹配和占位数据不得升级为 `blast_verified`，也不得用于生产或临床结论。

## 修复优先级

1. **P0：科学运行环境**  
   安装并锁定 BLAST+ 与 MAFFT 版本；配置C0资源目录、宿主基因组、目标序列集和近缘/共感染库。
2. **P0：WF-01基础闭环**  
   完成P2上下文/方向/配对扩增子判定、L3短区优先、八项评分降权契约测试。
3. **P0：真实序列验收集**  
   为至少一个病原建立≥20条WF-01代表序列、≥30条WF-05序列，以及宿主/近缘背景库，记录accession和数据库版本。
4. **P1：WF-02与P5**  
   实现多重Tm约束重设计重试，并配置内标数据完成WF-03。
5. **P1：WF-06/WF-07端到端**  
   在前述基础能力通过后进行全链路验收，不能用占位数据替代。

## 当前结论

当前代码不是“整个文档已严格实现”。它已经具备大部分工作流骨架和若干真实科学工具调用，但完整合规仍被BLAST+、MAFFT、C0数据库以及若干判定细节阻塞。在所有P0项通过前，系统必须保持 `PARTIAL`/`in_silico_only` 或明确失败，不得输出“完整验证通过”的结论。
