# WF-01 PRD v0.2 M0：需求冻结与可追溯基线

> 2026-08-10 裁决：新版 PRD 继续作为基础需求来源；PRD 发布后的甲方/专家确认须登记到决策台账。0.3.11 的“多序列默认进入 MAFFT/保守区”实现不得覆盖新版 PRD，该差异统一由 [DEC-WF01-003](WF01_PRD_V0.2_DECISION_LOG.md) 跟踪。

> 状态：`READY_FOR_REVIEW`  
> 需求权威来源：`引物智能体WF01_PRD_v0.2(1).pdf`  
> 适用范围：本期 Agent 后端，不含前端页面实现  
> 机器可读基线：[acceptance_manifest.json](../testdata/wf01_prd_v0_2/acceptance_manifest.json)

## 1. M0 的目标和边界

M0 不改变现有引物计算行为。它冻结本期范围、参数、规则、状态、报告字段和验收标准，防止后续开发继续沿用旧版“规则更新/简并”工作流。

M0 的交付物：

- 本文：人可读需求和冲突处理基线。
- [冲突裁决与变更台账](WF01_PRD_V0.2_DECISION_LOG.md)：持续维护每项业务决定、实施状态和验证证据。
- `testdata/wf01_prd_v0_2/acceptance_manifest.json`：机器可读常量、需求编号、验收用例和待决事项。
- `testdata/wf01_prd_v0_2/*.fasta`：M1 输入/预检的固定样例。
- `tests/test_wf01_prd_v02_m0_assets.py`：校验基线资产自身不被误改。
- [验收目录](WF01_PRD_V0.2_M0_ACCEPTANCE_CATALOG.md)：将需求映射到后续自动化验收。

## 2. 文档优先级

1. `引物智能体WF01_PRD_v0.2(1).pdf` 是本期基础范围与验收依据。
2. 甲方或业务专家在 PRD 后明确确认的变更，必须先登记到 [冲突裁决与变更台账](WF01_PRD_V0.2_DECISION_LOG.md)，再进入实现。
3. 本 M0 基线是对该 PRD 的结构化转录；二者有差异时以 PDF 和决策台账为准，并立即更新本基线。
4. 旧“规则更新.md”、`PHASE1.md`、`PHASE2.md`、`PHASE3.md`、旧版 `README.md` 和 P1-P6 Skill 文档仅作历史参考。
5. 历史内容只能补充新版未规定且不扩大本期范围的实现细节；不能改变新版 PRD 的阈值、流程或交付结论。
6. 新版未定义、但会影响科学结果、搜索完成判定或验收结论的内容必须登记为待确认项，不能默认继承旧规则。

## 3. 不可变范围

### 本期必须具备

- 同一批次接收一条或多条模板；**每条 FASTA 记录都是一个独立普通 TaqMan 靶标子任务**。
- 自然语言/文件输入的结构化解析、靶标-模板-宿主-近缘种-背景物种映射、问题确认。
- Primer3、硬规则、软规则、靶标命中、宿主排除、近缘种/背景物种 nt 评估。
- 用户档、默认档、L1、L2 的独立搜索和完整搜索记录。
- 靶标内去重、三维评分、固定 Top10、全部候选与排除原因。
- 批次和靶标状态、失败隔离、报告完整性和版本化重设计。

### 本期不得进入 WF-01 主链路

- 自动从病原/基因/accession 获取模板。
- 多序列比对、保守区/保守性评分、简并引物。
- L3、MGB、MGB 修正 Tm。
- 多重 qPCR、通道分配、跨靶标兼容性。
- 内标、已有引物验证/诊断、实验数据学习。
- 扩增子二级结构/ViennaRNA。
- SYBR Green、LAMP、RPA、数字 PCR。

## 5. 冻结的科学常量

| 项目 | 本期值 |
|---|---|
| 最小模板长度 | 80 nt |
| 固定推荐数 | 每靶标 Top10 |
| 引物 Tm 硬范围 | 50-65°C |
| 引物 ΔTm 硬上限 | 2°C |
| 扩增子硬范围 | 70-200 bp |
| 引物长度 | 18-28 nt |
| 普通探针长度 | 22-32 nt |
| 普通探针 Tm | 比正/反向引物平均 Tm 高 8-10°C |
| 引物 3′ G/C | 最后 5 nt 的 G+C 不超过 2；连续 G 不少于 4 时失败 |
| 探针位置 | 两引物间、不重叠、距两侧各不少于 5 bp |
| R09 | 3′ 二聚体 ΔG < -6.0 kcal/mol 或强自互补失败 |
| R10 | 涉及 3′ 的交叉二聚体 ΔG < -9.0 kcal/mol 失败 |
| 软扣分 | 低 Tm -5%、3′ 风险 -2%、发卡 -3%、非 3′ 弱二聚体 -3%，加法累积 |
| 评分权重 | 热力学 0.357、特异性 0.357、扩增子特征 0.286 |

完整的机器可读常量见 `acceptance_manifest.json`，后续不能在前端、提示词或工作流中复制另一套阈值。

| 历史实现/文档 | 本期裁决 | 后续动作 |
|---|---|---|

## 8. M0 退出条件

M0 的技术交付已经满足以下条件：

- 新版 PRD 的范围、参数、规则、评分、状态、报告和重设计已编号并可追溯。
- 历史冲突已明确裁决，且在 README 中标记新版 PRD 优先。
- M1-M7 的验收用例已有编号、样例输入和预期结论。
- 基线资产有自动自检，不依赖现有旧工作流结果。

M0 的业务签字和待确认项以决策台账中的实时状态为准。
