# WF-01 PRD v0.2：冲突裁决与变更台账

> 状态：`ACTIVE`  
> 建立日期：2026-08-10  
> 最后更新：2026-08-13  
> 适用范围：WF-01 v0.2 的需求、科学规则、代码、测试、报告和交付格式

## 1. 文档用途

本文件是 WF-01 v0.2 唯一持续更新的冲突裁决台账。需求基线、阶段合同、代码、测试、报告或历史发布说明之间出现差异时，必须在这里登记并裁决，不能只修改其中一处。

每解决一个问题，必须同时记录：

- 采用的最终规则及其来源；
- 被替代的旧规则；
- 受影响的文档、代码、测试和报告；
- 实施状态和验证证据；
- 尚未解决的风险或待确认项。

## 2. 权威来源优先级

1. 已由甲方或业务专家明确确认、并登记在本台账中的最新决定。
2. `引物智能体WF01_PRD_v0.2(1).pdf`（更新日期：2026-07-30）。
3. [M0 需求冻结与可追溯基线](WF01_PRD_V0.2_M0_REQUIREMENTS_BASELINE.md)。
4. M1～M7 阶段合同和 Agent 设计计划。
5. 代码、配置、测试、报告模板和发布说明；这些内容只能实现需求，不能反向覆盖需求。
6. 旧版“规则更新/简并”文档及其他历史资料，仅供追溯，不作为本期 WF-01 执行依据。

任何低优先级资料与高优先级来源冲突时，以高优先级来源为准，并在本台账登记。新版 PRD 没有定义、但会影响科学结果、排名、状态或验收结论的规则，必须标记为“待确认”，不得包装成 PRD 既定规则。

## 3. 完成判定

一项决定只有同时满足以下条件，才可标记为 `VERIFIED`：

1. 最终规则已经写入本台账和对应阶段合同；
2. 代码、配置和数据结构已一致实现；
3. 边界测试和回归测试通过；
4. HTML、Excel、PDF 及页面文案按同一规则展示；
5. 旧冲突文档已修改、标记为历史资料或明确被替代；
6. 验证证据和日期已经登记。

只改代码、只改报告或只改文档，都不能视为问题已经解决。

## 4. 状态定义

| 状态 | 含义 |
|---|---|

## 6. 已确认决定详情

### DEC-WF01-001：文档优先级

- 决定：新版 PRD 是本期产品范围和验收基准。后续发布说明、部署要求或代码改动不得在未登记业务确认的情况下覆盖 PRD。
- 被替代内容：`RELEASE_0.3.11.md` 中“多序列默认合并并进入 MAFFT”的实现决定不能继续覆盖新版 PRD。
- 验收：README、M0 基线、M1/M2 合同、代码和测试最终采用同一业务语义。

### DEC-WF01-002：引物绝对 Tm

- 业务确认：55℃和60℃处于平等地位；高于65℃不是扣分，而是直接排除。
- 最终规则：
  - `Tm<50℃`：硬性排除；
  - `50℃≤Tm<55℃`：通过绝对 Tm 硬门槛，但每个候选统一扣 5%，两条引物同时触发不重复扣分；
  - `55℃≤Tm≤65℃`：不因绝对 Tm 高低产生分差或软扣分；
  - `Tm>65℃`：硬性排除；
  - 正反向引物 `ΔTm≤2℃` 仍为硬门槛。
- 当前实现：绝对 Tm 评分及扣分主体已更新；仍需清理硬失败候选同时显示 `R01_SOFT WARNING` 的边界表现。
- 影响范围：M2 规则引擎、M3 评分合同、M6 报告、边界测试和旧规则文档。

### DEC-WF01-003：多条 FASTA

- PRD 规则：同一任务可以包含多条模板，但每条 FASTA 记录均形成独立靶标子任务。
- 禁止行为：把多条记录默认合并成一个靶标、调用 MAFFT、寻找保守区或生成保守性评分。
- 当前差异：代码仍默认 `alignment_target`，M2 仍包含 MAFFT/保守区分支，相关测试也在验证旧行为。
- 完成条件：默认且唯一的本期业务语义为“一记录一靶标”；MAFFT 等历史模块可保留在项目中，但不得进入 WF-01 v0.2 主链、状态、评分或报告。

### DEC-WF01-004：三维评分内部换算

- 2026-08-13 业务确认：`8℃≤探针 Tm－正反向引物平均 Tm≤10℃` 的候选在探针相对 Tm 子项中统一得 100；区间外由 R07 硬性排除，不进入排名。原“以 9℃为中心线性计分”的实现被替代。
- 2026-08-13 业务确认：扩增子硬范围保持 v0.2 的 `70≤x≤200 bp`；`x=70 bp` 保留 R02 边界 WARNING，长度子项为 70；`70<x≤150 bp` 为推荐范围，长度子项为 100；`150<x≤200 bp` 为非推荐但允许探索范围，长度子项统一为 70。原“70 bp=80、151～200 bp线性递减至0”的实现被替代。
- 参数档不变：默认档 `70～150 bp`、L1 `70～180 bp`、L2 `70～200 bp`；普通探针长度仍为 `22～32 nt`，模板最小长度仍为 `80 nt`。
- 受影响范围：M3 评分引擎、评分策略版本、M2/M3 边界测试、评分合同和报告中的评分明细。
- 尚待确认：正反向引物 `ΔTm` 的子分换算、扩增子 GC% 换算和特异性 `CAUTION` 的精确分值。

## 7. 待确认的评分细节

新版 PRD 规定三维权重、硬规则和软扣分，但没有规定以下换算曲线：

- 正反向引物 `ΔTm` 在 0～2℃之间如何换算为热力学子分；
- 扩增子 GC% 的满分区间和区间外换算公式；
- 特异性 `CAUTION` 对应的精确分值。

上述仍待确认的公式属于实现方案，不等于 PRD 或专家已确认规则。报告应如实标注评分策略版本，不得将尚未确认的部分写成“PRD规定”。
