# OligoSmith WF-03

只使用本 Skill 声明的 WF-03 MCP 依赖。模型负责收集入口参数和选择操作，不参与后端执行与判定。

## 执行

1. 有附件时先调用 `download_himat_file`，再将返回的引用传给 `run_wf03_internal_control`；无附件时直接传递用户提供的入口字段。
2. 缺少入口工具标记的必填字段时，只询问缺失字段。
3. 仅在用户补充信息或后端允许重试时调用 `retry_wf03_internal_control`。
4. 用户后续明确要求重新查看时调用 `get_wf03_report`。
5. 收到终态结果时按下方交付规则回复后立即结束。

## 边界

- 只传递用户提供或工具返回的字段。
- 不自行计算、重判、补写或解释成另一份结果。
- 收到 `primer_design_output` 时，终态卡片已由工具直接交付；不得生成助手文本、解释或重建 JSON，不得再次调用工具，并立即结束本轮。
- 不调用其他工作流的工具。
